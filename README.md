# PDF Selection Colors · PDF 选中底色

为 Zotero PDF 阅读器自定义临时文字选择底色，提供 Everforest 强调绿、莫兰迪预设、自定义颜色和不透明度调节。

Customize temporary PDF text-selection colors in Zotero, with Everforest and Morandi presets, a custom color picker, and adjustable opacity.

## 兼容性

- 当前版本：**1.0.6**。
- 允许安装和使用：**Zotero 10 系列**（`10.0` 至 `10.*`）。Zotero 10 内的小版本更新无需逐次发布适配包，遇到实际不兼容时再修复。
- 1.0.6 已在 Windows、Zotero 10.0.7 中完成实际 PDF、旧安装包清理及重启检查；历史版本在 10.0.6 中检查过。扩大允许使用的范围不代表已逐个验证 Zotero 10 的所有版本；macOS 与 Linux 尚未验证。Zotero 11 及其他主要版本需另行检查。

## 下载与安装

1. [下载 pdf-selection-colors-1.0.6.xpi](https://github.com/PeterBenjaminZhu/zotero-pdf-selection-colors/raw/refs/heads/main/pdf-selection-colors-1.0.6.xpi)，保存 `.xpi` 文件。
2. 在 Zotero 中打开 **工具 → 插件**。
3. 点击齿轮按钮，选择 **Install Plugin From File… / 从文件安装插件**，选择下载的 `.xpi`。
4. 安装后重新启动一次 Zotero。

升级保留已经保存的颜色和不透明度，无需修改现有主题文件。

## 自动更新

从 **1.0.4** 开始，插件使用 Zotero 自带的更新功能。版本信息和安装包由本 GitHub 仓库提供，更新时核对安装包的 SHA-256 校验值。

首次安装 1.0.4 或更高版本会开启此插件的自动更新。以后可以在 **工具 → 插件 → PDF 选中底色 → 详情** 中调整自动更新设置；插件会保留之后的手动选择。

也可以通过插件管理中的 **Check for Updates / 检查更新** 主动检查。自动更新的检查和安装时间由 Zotero 安排；网络需要能够访问 GitHub 的文件下载服务。

**1.0.3 及更早版本需要先手动安装一次当前新版**，之后即可通过 Zotero 获取本仓库发布的兼容版本。1.0.4 已支持通过 Zotero 更新至 1.0.5。

版本信息：[updates.json](https://raw.githubusercontent.com/PeterBenjaminZhu/zotero-pdf-selection-colors/main/updates.json)。

## 使用

### 更新后的旧安装包清理

清理功能默认关闭。在 **工具 → PDF 选中底色… → 旧安装包清理** 中先选择独立的安装包目录，再启用功能。首次启用、修改目录或升级后，重新启动 Zotero，在实际 PDF 中选择文字并确认底色正常，然后点击 **检查安装包目录**。

程序会按正式发布记录下载并校验当前版本安装包，显示待删除旧包的绝对路径、版本、大小和 SHA-256。核对后点击 **已确认 PDF 选择正常，开始清理**，永久删除清单中的旧安装包。每次清理均需确认。

仅处理所选目录第一层、正式命名且内部插件 ID、版本和摘要全部匹配的旧安装包。当前版本、更高版本、其他插件、改名包、无法核验的文件和子目录均保留。程序拒绝符号链接和 Windows 目录重定向，也拒绝 Zotero profile、程序目录及磁盘根目录。

当前包缺失时先补充并校验；已有同名包内容不同则停止。网络、权限、摘要或文件变化导致检查失败时，保留文件并显示具体原因。删除中途失败时停止后续操作，已经删除的文件及剩余清单写入本地记录；处理错误后须重新检查并确认。设置界面显示记录目录。清理失败单独报告，颜色功能继续运行。

### 颜色设置

打开 **工具 → PDF 选中底色…**。

默认采用 **强调绿 `#A7C080`，不透明度 25%**。调整后自动保存，立即应用到已打开的 PDF；重新启动后保留设置。平时调整颜色无需重启 Zotero。

| 预设 | 颜色代码 |
| --- | --- |
| Everforest 强调绿 | `#A7C080` |
| 莫兰迪灰绿 | `#A3B5A4` |
| 莫兰迪灰蓝 | `#9CAFB7` |
| 莫兰迪灰紫 | `#B3A3B5` |
| 莫兰迪灰粉 | `#C2A3A3` |
| 莫兰迪灰褐 | `#B8AD96` |

支持自定义选色和六位颜色代码输入。不透明度提供滑动条与数字输入，范围为 **0%–100%**，数值越大，底色越明显。0% 完全透明，100% 完全不透明。

点击 **恢复默认**，恢复强调绿和 25% 不透明度。

## 修改范围

插件只调整普通文字选择时的临时底色。正文、公式、图表、已有批注、高亮工具和下划线工具继续使用原有颜色。

论文及 Zotero 原有的链接底色、鼠标经过提示保持原样。链接改为灰绿后，会与同色的文字选择预设重复，选择链接时也容易发生底色重叠，因此当前版本保留原链接效果。

## 停用与卸载

在 **工具 → 插件** 中停用 **PDF 选中底色**，即可恢复 Zotero 原有的蓝色选择效果；重新启用后恢复保存的配色。也可通过插件管理移除此插件。现有主题继续保留。

## 发布新版本

维护者发布新版时，应同时上传对应版本的安装包，并更新 `updates.json` 中的版本、下载地址、校验值和适用 Zotero 版本范围；同时更新 README、版本记录和 `SHA256SUMS`。仅上传安装包时，Zotero 不会发现新版本。已经发布的版本安装包应保留原文件内容。
